# M512 Viral Content

منصة لاكتشاف المقاطع الفيروسية على يوتيوب وشورتس وتيك توك وإنستغرام، وتحليل أسباب انتشارها بالذكاء الاصطناعي، ثم تحويلها إلى سكريبت في Claude.

- `index.html` + `assets/` : الواجهة (بدون خطوة بناء)
- `api/` : دوال Vercel بلغة Python (بحث يوتيوب، الإضافة بالرابط، التحليل، الإدارة)
- `lib/m512.py` : المنطق المشترك (درجة الانتشار، yt-dlp، Gemini)
- `supabase/schema.sql` : قاعدة البيانات والصلاحيات
- `extension/` : إضافة كروم (نسخة مضغوطة في `downloads/`)
- `tests/test_server.py` : اختبارات المنطق

خطوات التشغيل في **SETUP.md**.
